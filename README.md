# Faisal Portfolio

A responsive portfolio website built with:

- HTML5
- Bootstrap 5
- CSS3
- jQuery

## Run locally

Open `index.html` in a browser, or use the VS Code Live Server extension.

## Before publishing

1. Replace `images/faisal-raheem-baloch.png` with your own image.
2. Replace email, GitHub, and LinkedIn links.
3. Replace project `href="#"` values with real project URLs.
4. Connect the contact form to an email service or backend API.
